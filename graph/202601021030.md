# Knowledge Compounds

Small investments in understanding accumulate over time. A note written today connects to one from last month, which connects to an insight from last year.

This compounding only works with:

- Consistent input (daily practice)
- Meaningful connections (linking ideas)
- Retrieval (revisiting and using notes)

The compound interest of knowledge is real, but only if you keep making deposits.
