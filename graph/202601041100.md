# Linking Ideas

The link is the fundamental unit of value in a note system. Notes without links are isolated islands. Links create a network where ideas can travel.

Good links are:

- Bidirectional (you can navigate both ways)
- Meaningful (connected for a reason, not just co-occurrence)
- Surprising (connecting ideas from different domains)

The best insights come from unexpected connections between familiar ideas.
