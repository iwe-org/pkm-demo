# Document checklist

Income:

- [ ] W-2 (employer)
- [ ] 1099-INT (bank interest)
- [ ] 1099-DIV (dividends)
- [ ] 1099-NEC (freelance, if any)

Deductions:

- [ ] Home office calculation
- [ ] Business expenses summary
- [ ] Charitable donation receipts
- [ ] Medical expenses (if significant)

Other:

- [ ] Last year's return (for reference)
- [ ] ID for e-file
- [ ] Bank account info for refund
